# Reminder

**Небольшая напоминалка для Windows, которая всегда видна поверх окон. У каждой задачи свой таймер и свои рабочие часы. Когда время подходит, по центру экрана появляется карточка и висит, пока вы на неё не отреагируете.**

## Зачем

Мелкие регулярные дела легко забыть, когда погружён в работу: выпить воды, размяться, проверить трекер, отправить еженедельный отчёт, оплатить аренду. Всплывашки календаря исчезают через пару секунд, уведомления на телефоне смахиваются не глядя.

Reminder держит поверх окон полупрозрачное окно, где для каждой задачи идёт свой отсчёт. Когда таймер истекает, по центру основного экрана появляется карточка. Закрыть её нельзя. Она уходит, только когда нажмёшь **Mark as done** или **Snooze**, так что ничего не проскочит мимо.

Приложение рассчитано на рабочий день:

- короткие таймеры идут только в ваши рабочие часы и в выбранные дни;
- если ПК спал или был выключен, вы получите сводку пропущенного.

## Возможности

- **Свой таймер у каждого ивента**: месяцы, недели, дни, часы и минуты (1 месяц = 30 дней).
- **Повтор** заданное число раз или пока не остановишь. В счётчик идёт только *Done*, *Snooze* не считается. После последнего *Done* ивент уходит в архив.
- **Рабочие часы и дни** у каждого ивента (например, Пн–Пт 07:30–16:00 или весь день):
  - таймеры короче суток вне этих часов встают на паузу и с началом часов запускаются заново с полного интервала;
  - таймеры от суток считают календарное время, и если срабатывание выпало на нерабочее время, ждут ближайшего начала.
- **Уведомление по центру экрана**:
  - висит поверх всех окон, закрыть или свернуть его нельзя;
  - подстраивается под длинный текст, а сработавшие одновременно ивенты показывает по очереди, начиная с самого раннего;
  - играет звук: системный или ваш файл MP3, WAV, OGG.
- **Сводка пропущенного** после сна или выключения: каждый ивент попадает в неё один раз, есть *Done* на строке и *Mark all as done*.
- **Категории** с цветами: три по умолчанию (Work, Health, Personal), до 20.
- **Архив** с двумя способами вернуть ивент: со старым таймером или с новым.
- **Окно**:
  - без рамки и полупрозрачное, с размытием фона, прозрачность от 40 до 100 %;
  - поверх всех окон, размер меняется за любой край, есть закрепление позиции (булавка);
  - режим click-through;
  - сворачивается в трей и, если нужно, запускается вместе с Windows.
- **Три темы**: Ivory, Clay и Graphite. Работают горячие клавиши и режим уменьшения анимации.
- **Приватность**: без аккаунта, без интернета, без телеметрии. Данные лежат в одном файле на вашем ПК.

## Требования

- Windows 10 (версия 2004 или новее) или Windows 11, 64 бит.

## Установка

1. **[Скачайте Reminder-Setup.exe](https://github.com/FLAIR-soft/Simple_Reminder/releases/latest/download/Reminder-Setup.exe)**: последняя версия, один файл. Все версии лежат на странице [Releases](https://github.com/FLAIR-soft/Simple_Reminder/releases). Можно и собрать самому (см. [Разработка](#разработка)).
2. Запустите установщик. Он не подписан, поэтому Windows SmartScreen может показать синее окно. Нажмите **Подробнее → Выполнить в любом случае**.
3. Выберите папку и завершите установку. Reminder запустится в правом верхнем углу экрана, а в трее появится его значок.

Чтобы обновить приложение, установите новую версию поверх старой: ивенты сохранятся. Удалить приложение можно через **Параметры → Приложения**. Файл с данными при этом остаётся на месте, так что при повторной установке всё вернётся.

## Как пользоваться

### Создать ивент

1. Нажмите **New event** или клавишу `N`.
2. Введите **название**. Если хотите, добавьте **описание** и выберите **категорию**.
3. Заполните **таймер**. Только нужные поля, например `Hours 2` или `Minutes 45`. Под полями видно итог, например *Every 2 h*.
4. **Повтор**:
   - выключен: разовое напоминание, после *Done* уходит в архив;
   - включён: укажите число раз или выберите **Until I stop**.
5. **Рабочие часы**: выберите **All day** или задайте часы в 24-часовом формате (например, `07:30`–`16:00`), затем отметьте дни.
6. Нажмите **Save** или `Ctrl+S`.

Если короткий таймер не помещается в рабочие часы (например, 2 ч в окне на 1 час), форма объяснит почему и не сохранит ивент.

### Главное окно

- **Active**: все идущие ивенты с отсчётом, полоской прогресса, счётчиком повторов и расписанием. Ивенты, которые ждут вашего *Done*, стоят сверху.
- **Archive**: завершённые ивенты и те, что вы убрали сами.
- В меню **⋯** на карточке есть **Edit** (`E`), **Move to archive** и **Delete**. Для удаления кнопку **нужно удерживать около секунды**, чтобы случайный клик ничего не стёр.
- В архиве **⋯ → Restore** даёт два варианта:
  - *Keep previous timer*: прежние настройки, счётчик повторов обнуляется;
  - *Set new timer*: открывается форма.

### Когда срабатывает напоминание

По центру основного экрана появляется карточка:

- **Mark as done**: засчитывается один повтор. Следующий цикл отсчитывается от этого момента.
- **Snooze for N min**: напоминание вернётся через указанное число минут (от 1 до 1440, значение по умолчанию задаётся в настройках). В повторы это не идёт.

Если сработало сразу несколько ивентов, они показываются по очереди (*1 of 3 waiting*). Остальные таймеры пока идут дальше. Ивент в ожидании висит, пока вы не отреагируете, даже если его рабочие часы уже закончились.

### После сна или выключения

При следующем запуске ПК появится сводка того, что должно было сработать, пока он был выключен. Нажмите **Done** у каждой строки или **Mark all as done**. Пока сводка открыта, обычные уведомления ждут.

### Настройки

Открываются значком шестерёнки.

| Настройка | Что делает |
|---|---|
| Theme | Ivory, Clay или Graphite |
| Window opacity | 40–100 %; меняется только фон, текст и кнопки остаются чёткими |
| Blur the background | Размывает то, что за окном. Пока включено, Reminder не виден на скриншотах и в демонстрации экрана. Выключите, если нужно показать окно на созвоне |
| Always on top | Окно всегда поверх других |
| Lock position | То же, что булавка: окно нельзя сдвинуть или изменить его размер |
| Click-through | Клики проходят сквозь окно. **Выключить можно только из трея**: правый клик по значку Reminder, снять галочку *Click-through* |
| Start with Windows | Reminder запускается в трее при входе в систему |
| Sound | Системный звук или ваш файл MP3, WAV, OGG (до 10 МБ), есть кнопка для проверки звука |
| Default snooze | Сколько минут подставлять в уведомление |
| Categories | Переименовать, сменить цвет, добавить, удалить (удалить можно только пустую категорию) |

### Меню трея

Правый клик по значку в трее: **Show Reminder**, **New event**, **Always on top**, **Click-through**, **Start with Windows**, **Quit**.

Крестик в окне только прячет его в трей, таймеры продолжают идти. Полностью выйти можно через **Quit** в трее.

### Клавиатура

| Клавиша | Действие |
|---|---|
| `N` | Новый ивент |
| `E` | Изменить выбранный ивент |
| `Ctrl+S` | Сохранить форму |
| `Esc` | Закрыть меню, вернуться назад, отменить форму |

Однобуквенные сочетания не срабатывают, пока вы печатаете в поле.

## Ваши данные

- Всё хранится в `%APPDATA%\Reminder\reminder-data.json`.
- Каждое сохранение атомарное, предыдущая версия лежит рядом как `reminder-data.json.bak`.
- Если файл повреждён, приложение покажет баннер с **Retry** и ничего не сохранит, пока проблема не решена. **Start fresh** оставляет повреждённый файл рядом с новым, он никогда не удаляется.
- Приложение не выходит в интернет.
- Для размытия фона приложение смотрит на экран под своим окном как на живое видео в низком разрешении. Картинка существует только в памяти: её не записывают, не сохраняют и никуда не отправляют. Выключите размытие, и это прекратится.

## Разработка

Стек: Electron, Vite (electron-vite), React, TypeScript (strict), zod, i18next, Tabler Icons, Vitest и Playwright.

```bash
npm install
npm run dev         # запуск с горячей перезагрузкой
npm test            # unit-тесты (планировщик, хранилище), TZ=Europe/Berlin
npm run test:e2e    # сборка + сквозные тесты на настоящем приложении (Playwright _electron)
npm run typecheck
npm run dist        # проверка типов, сборка и установщик NSIS в release/
```

Структура:

```
src/shared/     модель (схемы zod), расчёты времени, планировщик: чистые функции (state, now) → state
src/main/       окна, трей, хранилище, IPC с проверкой, размытие, безопасность
src/preload/    типизированный мост window.reminder
src/renderer/   интерфейс на React: главное окно, уведомление, сводка пропущенного
tests/unit/     тесты планировщика и хранилища (переход на летнее время, смена часов, сон, очереди…)
tests/e2e/      тесты Playwright на собранном приложении
docs/           план, чек-лист запуска, отчёты stress-test и security-audit
```

Безопасность:

- интерфейс работает в песочнице, с изоляцией контекста и без доступа к Node;
- каждый IPC-вызов проверяется по схеме и по отправителю;
- действует строгая политика CSP;
- навигация, новые окна и все разрешения запрещены, кроме видеопотока экрана для размытия;
- в сборке включены защитные настройки Electron (fuses).

Подробности в [docs/security-audit.md](docs/security-audit.md).
